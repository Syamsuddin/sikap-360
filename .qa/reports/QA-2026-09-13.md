## Medium
### BUG-001 [Medium] Origin cacat melewati pemeriksaan Origin (Tahap 4)
- Lokasi: `public/api.php:11`
- Bukti:
  ```
  curl -b <cookie ASN> -H 'Origin: http://127.0.0.1:8765.evil.test' -d '{}' api.php?action=bootstrap → 200
  curl -b <cookie ASN> -H 'Origin: http://evil.test'                -d '{}' api.php?action=bootstrap → 403
  php -r 'var_dump(parse_url("http://127.0.0.1:8765.evil.test"));' → bool(false)
  ```
- Akar masalah: `parse_url()` mengembalikan `false` untuk Origin tak valid; kondisi `if($origin && …)` menganggapnya "tanpa Origin" sehingga lolos.
- Dampak: hanya defense-in-depth (browser tidak pernah mengirim Origin cacat; SameSite=Strict + token CSRF tetap melindungi). Tetap layak ditutup.
- Rekomendasi: tolak bila header Origin ada tetapi tidak bisa di-parse — patch `.qa/patches/BUG-001.diff` (terverifikasi: reproduksi 403 pada salinan patch, regresi penuh hijau).
- Test pereproduksi: `tests/api_invariants.php` → "Origin http://127.0.0.1:8765.evil.test → 403".

### BUG-002 [Medium — dampak operasional tinggi] Periode draft masa depan menjadi periode default semua pengguna (Tahap 4/6)
- Lokasi: `app/Api.php:60-61` (`bootstrap`)
- Bukti:
  ```
  INSERT INTO periods(name,start_date,end_date) VALUES('Masa Depan','2027-03-01','2027-03-31');   -- status draft
  bootstrap {} sebagai pegawai3 (asli 8765) → period "Masa Depan" draft | tasks: 0
  bootstrap {} sebagai pegawai3 (patch 8766) → period "Semester II 2026" open | tasks: 12
  E2E: setelah test admin membuat periode → 2 test ASN gagal "element(s) not found" (daftar tugas kosong)
  ```
- Akar masalah: `ORDER BY start_date DESC` lalu `$periods[0]` tanpa memandang status; front-end hanya menyimpan pilihan periode di `sessionStorage` (hilang di tab/sesi baru).
- Dampak: begitu admin menyiapkan periode berikutnya, seluruh ASN melihat "Total penugasan 0" di dashboard dan Penilaian saya sampai memilih periode manual → risiko penilaian terlewat.
- Rekomendasi: default = periode `open` terbaru, lalu `closed`, lalu `published`; `draft` hanya bila tidak ada yang lain — patch `.qa/patches/BUG-002.diff` (terverifikasi). Urutan prioritas ini usulan agent, lihat D-03.
- Test pereproduksi: `tests/api_invariants.php` → "bootstrap default = periode open, bukan draft masa depan (BUG-002)"; `e2e/qa-crawl.spec.ts` bila dijalankan setelah test admin.
