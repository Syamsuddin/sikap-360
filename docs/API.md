# Kontrak API SIKAP 360

Endpoint relatif: `api.php?action=NAMA_AKSI`. Semua permintaan POST, Content-Type `application/json`, cookie sesi SIKAPSESSID. Mutasi selain login wajib header `X-CSRF-Token` dari bootstrap. Origin harus cocok dengan APP_URL. API tidak membuka CORS.

| Aksi | Peran | Isi JSON |
| --- | --- | --- |
| login | Publik | username (NIP atau email; berisi "@" dicari sebagai email, selain itu sebagai NIP dengan spasi diabaikan; kunci lama email tetap diterima), password |
| info | Publik | objek kosong; mengembalikan kabupaten_name |
| bootstrap | ASN/admin | period_id opsional |
| logout | ASN/admin | objek kosong |
| password_change | ASN/admin | current_password, password |
| save_draft | Pemilik tugas | id, version, answers objek `{1:4,2:5}` berkunci ID indikator periode tugas itu (BerAKHLAK atau tematik periode itu; indikator lain 422), feedback |
| submit | Pemilik tugas | period_id, ids array ID tugas. Setiap tugas wajib menjawab seluruh indikator periode: tujuh BerAKHLAK ditambah lima tematik bila periode memilikinya (selain itu 422) |
| employee_save | Admin / Admin OPD | id opsional, name, nip, position, opd_id (admin OPD: diabaikan, selalu OPD-nya), unit, grade, email, password (12–128 karakter; pegawai baru: kosong = NIP, edit: kosong = tidak diganti), supervisor_id opsional, role opsional (asn/admin_opd/admin; hanya admin kabupaten) |
| period_create | Admin kabupaten | year (2000–2100), quarter (1–4) |
| period_status | Admin kabupaten | period_id, status |
| period_delete | Admin kabupaten | period_id. Hanya periode draf tanpa penugasan; periode berstatus lain, draf yang sudah memiliki penugasan, atau satu-satunya periode menghasilkan 409; periode tidak ada 404. Bobot dan indikator tematik periode ikut terhapus. Tercatat di audit (period_deleted: nama dan tema) |
| assignment_create | Admin / Admin OPD | period_id, subject_id, rater_id, rater_role (keduanya satu OPD) |
| assignment_delete | Admin / Admin OPD | id |
| supervisor_set | Admin / Admin OPD | employee_id, supervisor_id (null atau 0 = tanpa atasan; admin OPD: harus satu OPD, admin kabupaten boleh lintas OPD) |
| assignment_list | Admin / Admin OPD | period_id, opd_id opsional (admin kabupaten; admin OPD: diabaikan), role, status, q (nama pegawai atau penilai), page. Mengembalikan rows (10 per halaman: id, subject_id, rater_id, rater_role, status, opd_id, opd_code, subject_name, rater_name), total, page, pages, per, stats {total, submitted} |
| assignment_generate | Admin / Admin OPD | period_id (periode harus draft), opd_id opsional (admin kabupaten: batasi ke satu OPD; admin OPD: diabaikan) |
| opd_save | Admin kabupaten | id opsional, name, code (2–20 huruf/angka, disimpan huruf besar), active |
| settings_save | Admin kabupaten | kabupaten_name |
| weights_save | Admin kabupaten | period_id periode berstatus draf dan weights: objek tiga kondisi berkunci peran terurut, mis. `{"atasan,bawahan,rekan":{"atasan":60,"rekan":25,"bawahan":15},"atasan,rekan":{"atasan":75,"rekan":25},"atasan,bawahan":{"atasan":85,"bawahan":15}}`; tiap bobot bilangan bulat 1–99, jumlah per kondisi 100 (selain itu 422). Periode yang sudah dibuka, ditutup, atau dipublikasikan menghasilkan 409; periode tidak ada 404. Hanya bobot periode itu yang berubah. Mengembalikan weights tersimpan |
| thematic_save | Admin kabupaten | period_id periode berstatus draf, theme (1–120 karakter), indicators: daftar tepat 5 objek `{"name":…,"description":…}` (name 1–80 karakter, description 1–600 karakter, nama tidak boleh sama tanpa membedakan huruf besar; selain itu 422). Menggantikan seluruh butir tematik periode itu dan mencatat tema serta nama butir lama dan baru di audit (thematic_saved). Periode yang sudah dibuka, ditutup, atau dipublikasikan menghasilkan 409; periode tidak ada 404. Mengembalikan theme dan count |
| admin_dashboard | Admin kabupaten | period_id. Mengembalikan period (id, name, status, end_date), summary (total, submitted, draft, pending, subjects, subjects_done, raters, raters_done, employees, opds, opds_assigned, opds_done, opds_started), roles (atasan/rekan/bawahan: total, submitted), opds (semua OPD urut nama: id, name, code, active, employees, total, submitted, draft, pending, subjects, subjects_done, raters, raters_done), dan generated_at. Penugasan dan pegawai dinilai dihitung menurut OPD pegawai yang dinilai; penilai menurut OPD penilai. subjects_done = pegawai yang seluruh penugasannya terkirim; raters_done = penilai yang seluruh tugasnya terkirim. Hanya jumlah, tanpa nilai, jawaban, catatan, atau nama pegawai. Periode tidak ada 404 |

Peran akun: `admin` (administrator kabupaten: semua OPD, periode, OPD, pengaturan), `admin_opd` (administrator satu OPD: pegawai, struktur, dan pasangan penilai OPD-nya sendiri; aksi kabupaten → 403; pegawai di luar OPD-nya → 403), `asn`. Satu instalasi = satu kabupaten (nama di tabel settings, default Hulu Sungai Selatan) dengan banyak OPD; periode berlaku serentak untuk seluruh OPD.

bootstrap mengembalikan user (termasuk opd_id, opd_name, opd_code), settings, opds (dengan employee_count), periods, periods (bagi admin juga assignments_total dan assignments_submitted per periode; admin OPD: pegawai dinilai di OPD-nya), period (dengan weights: bobot komposisi periode itu, dan theme: tema indikator tematik atau null), indicators (id, category `berakhlak`/`tematik`, name, description: tujuh BerAKHLAK lalu butir tematik periode terpilih), tasks, result (score rata-rata seluruh indikator periode, dimensions per indikator beserta category, dan categories: rata-rata tiap kategori sebagai rincian), csrf. employees (admin) memuat supervisor_id, atasan langsung, beserta supervisor_name, supervisor_position, dan supervisor_opd_id (atasan lintas OPD tetap terbaca di lingkup admin OPD); rekan sejawat (pejabat: sesama pejabat seatasan; staf: staf lain satu unit dalam OPD yang sama) dan bawahan langsung diturunkan klien dari kolom ini bersama unit. Tanpa period_id (atau period_id tidak dikenal), periode default adalah periode berstatus open dengan tanggal mulai terbaru; bila tidak ada, berturut-turut closed, published, lalu draft. employees hanya berisi data untuk admin; untuk admin OPD dibatasi ke OPD-nya. Daftar penugasan tidak disertakan pada bootstrap (jumlahnya dapat ratusan ribu); ambil lewat assignment_list, yang menyaring admin OPD berdasarkan OPD pegawai yang dinilai. Setiap baris employees memuat opd_id, opd_name, opd_code, role. Jawaban tasks hanya milik penilai yang sedang login. result hanya untuk pegawai yang sedang login. Sesi berlaku dengan batas tidak aktif 30 menit. Penggantian kata sandi membatalkan sesi lain melalui auth_version.

supervisor_set dan employee_save menolak atasan diri sendiri (422), atasan tidak aktif/tidak ada (404), dan struktur melingkar (409). Atasan lintas OPD (mis. Bupati bagi kepala OPD) hanya dapat ditetapkan atau dilepas admin kabupaten; admin OPD yang mencoba menetapkan, mengganti, atau melepasnya ditolak (422), tetapi boleh menyimpan pegawai dengan atasan lintas OPD yang sudah ada. NIP berupa 18 digit, atau kode huruf besar 4–18 karakter (huruf, angka, strip; diawali huruf) untuk pejabat non-ASN, mis. BUPATI-HSS, yang juga dipakai untuk masuk. assignment_generate mengembalikan created, skipped, warnings (diawali kode OPD): tiap pegawai aktif yang punya atasan mendapat penilai atasan; rekan bagi pejabat (pegawai yang punya bawahan aktif) adalah sesama pejabat dengan atasan yang sama, termasuk lintas OPD (kepala OPD di bawah Bupati saling menjadi rekan; struktur dibaca dari seluruh OPD walau opd_id dibatasi, sedangkan yang dinilai hanya pegawai OPD tersebut), dan bagi staf adalah staf lain satu unit (UNOR: opd_id + unit, tanpa membedakan huruf besar); bawahan langsung menjadi bawahan; kelompok rekan dan bawahan dipakai berapa pun jumlahnya (minimal 1); pegawai yang hanya akan punya penilai atasan dilewati seluruhnya karena komposisi tidak sah; pasangan (period, subject, rater) yang sudah ada dilewati; pegawai tanpa atasan tidak dinilai. Menjalankan ulang bersifat idempoten.

save_draft mengembalikan version baru. Perbedaan version menghasilkan HTTP 409. Client wajib memuat ulang sebelum mengulang penyimpanan konflik. submit memvalidasi semua tugas lebih dahulu dan menyimpan dalam satu transaksi. Salah satu tugas tidak valid membatalkan seluruh batch.

Semua perubahan jawaban serta status periode mengunci baris periode terlebih dahulu, sehingga pengiriman dan penutupan periode tidak berjalan melampaui satu sama lain. Kunci tugas diambil dengan urutan ID untuk pengiriman batch.

period_create membuat satu triwulan kalender: nama (`Triwulan I 2027`), start_date, dan end_date diturunkan server dari year + quarter. Triwulan yang sudah ada menghasilkan 409.

Status periode: draft → open → closed → published. closed → open diizinkan sebelum publikasi. Penyimpanan dan pengiriman hanya ditentukan status: diterima selama periode open, termasuk sebelum tanggal mulai atau setelah tanggal selesai, dan ditolak (409) setelah periode ditutup. published bersifat final di aplikasi versi ini. Bobot komposisi melekat pada tiap periode (periods.weights): period_create menyalin bobot periode terbaru, weights_save hanya diterima selama periode draf, dan perubahan status tidak mengubah bobot. Periode tanpa bobot (sebelum v1.8) memakai bobot bawaan, yang ditulis ke periode saat dibuka. Indikator tematik juga melekat pada tiap periode (indicators.period_id, tema di periods.theme): period_create menyalin tema dan lima butir tematik periode terbaru dengan ID baru, thematic_save hanya diterima selama periode draf, dan periode tanpa butir tematik (sebelum v1.9) tetap dinilai dengan tujuh indikator BerAKHLAK. Nilai akhir adalah rata-rata seluruh indikator periode dengan bobot setara.

Pembatasan login: 10 kegagalan per akun atau 100 kegagalan per alamat IP dalam 15 menit menghasilkan 429. Alamat IP diambil dari X-Forwarded-For hanya bila permintaan datang dari proxy yang terdaftar pada TRUSTED_PROXIES.

Kode respons: 200 berhasil, 400 JSON rusak, 401 sesi/login, 403 otorisasi/CSRF/origin, 404 data tidak ditemukan, 409 konflik, 413 ukuran, 415 tipe konten, 422 validasi, 429 pembatasan login, 503 database.
